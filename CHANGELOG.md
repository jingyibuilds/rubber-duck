# Changelog

## 0.1.0 (2026-10-28)

First release.

- A light framework: five fixed points (anchor, tags, Markdown template, one question, wrap-up); everything else is left to judgment.

- Three rules against the usual failures of an AI thinking partner: hold the anchor (drift), label everything you add (running off), don't just agree (confirming).
- Each reply is a map in a fixed Markdown template: anchor, through-line, tagged parts, settled / open, parked. An optional one-page HTML version where the host can render it.
- Optional checking and challenging, offered once the map settles.
- Optional log for long conversations, with notes on how the user is thinking; can be resumed in a new session.
